## 2. 血缘：它自称的「原版」是哪来的

`source/mota.js` 第 3–4 行原文（**这是它自己的声明，不是本项目的推断**）：

```
 * 数据来源：《魔塔50层》Flash 原版（h5mota 官方复刻数据），见 mota-data.js
 * 战斗公式与特殊属性均按原版实现（对照 h5mota 51_maze functions.js）：
```

`source/mota-data.js` 文件头原文：

```
/* 魔塔50层 —— 原版数据（由 tools/build_data.py 从 h5mota 官方原版复刻数据生成，请勿手改） */
```

⇒ 血缘链：

```
原版 Flash《魔塔50层》
   └─ h5mota 社区「官方复刻数据」（工程代号 51_maze，含 functions.js）
        └─ githubxzw/mota50-deluxe（tools/build_data.py 由上面那份数据生成 mota-data.js）
             └─ 【本项目】reference/mota50-deluxe/ 归档 —— 仅取数据与对白文本
```

**关键判断**：本目录的数据**不是** deluxe 作者自己编的，而是从 **h5mota 的复刻数据**转出来的。
所以「照搬原版对白」的**原版**指的是原版 Flash 游戏的台词，deluxe 只是它的一个中转载体。

⚠️ 另一条线索：上游 README 开头写「基于《魔塔50层》复刻工程（`../mota`）的全面视觉升级版」，
但**作者名下没有那个 `../mota` 仓库**（`gh search repos` 查过）。⇒ 那句引用指向的是
h5mota 的复刻工程，不是 GitHub 上的另一个仓库。（对照：`../mota50/` 收录的 `m8705/MAGIC-TOWER-JS`
是**另一个**独立复刻，与本归档**不是**同源，见 §5。）

**事实**：上游仓库 `githubxzw/mota50-deluxe` **没有 LICENSE 文件**（归档时已确认；下载到的
候选目录里也没有）。⇒ 严格按著作权法，**默认保留所有权利**，本项目无权整体复制它的代码。

**本项目怎么用它**（边界写死，改代码时不要越界）：

| 用途 | 允许 | 理由 |
|---|---|---|
| **对白文本**（智者提示 / 商人叫卖 / 剧情台词） | ✅ 已采用，落进 `data/npcs.json` | 短句台词**源于原版游戏**，deluxe 只是转录；本项目与它同为复刻工程，用途非商业、已在此处明确署名溯源 |
| 坐标/地图结构**对账**（当参照物量一致性） | ✅ 允许 | 用于**验证**本项目自己的地图，不复制 |

**如果将来上游补上 LICENSE**：以它为准重新评估本文件（`mota-data.js` 若随 LICENSE 变更为

## 4. 坐标映射 = 减 1（使用本数据前必读）

deluxe 的地图是 **13×13**（外围一圈边界墙），本项目是去掉外框的 **11×11**。

- `MOTA_DATA.floors[].talk` 的键（如 MT1 的 `"7,10"`）**减 1** 后精确落在本项目的 NPC 实体上：
  MT1→(6,9)=`sage`、MT2→(10,3)、MT12→(10,0)+(0,0)、MT21→(5,5)、MT36→(0,0)…
  40 层里只有 3 处差 1–2 格（MT7 / MT23 / MT38）。
- **全塔地形逐格比对**：6171 格中 5988 格相同，**一致率 97.03%**。
  差异集中在 MT23（92 格：deluxe 用 43 处 `closeWall` **运行时生成**暗墙迷宫，本项目的地图源把假墙**静态烘进**了地图）、
  MT50（40 格，`*→#`）、MT29/MT35（小偷暗道），其余 15 层各差 1–4 格。

⇒ 结论：**两个源是同一张地图**，deluxe 的是「原始设计」，本项目的地图是静态化后的结果。
⇒ 因此导入脚本 `tools/import-deluxe-dialogue.mjs` 里坐标一律 `-1`，**且落表前必须用
`hasHome(floor, id)` 确认该层真的有对应 NPC 实体**（否则会写出「定义了但地图上没有」的死数据）。

⚠️ 打印 deluxe 的 13×13 map 做人工核对时**必须先固定宽度**（`printf "%4d"`）——
`20/120/220` 这类两位/三位数会让行宽粘连（`0201202201`），看起来像数据损坏，其实不是。

## 5. 与 `../mota50/`（m8705）的差异对照

同一款游戏的两份独立复刻，各有硬伤与长处 —— **两份都留着**，用途不同：

| 维度 | `../mota50/`（m8705） | 本目录（githubxzw/deluxe） |
|---|---|---|
| 授权 | ✅ GPL-3.0（有 `LICENSE/`） | ❌ 无 LICENSE |
| 数据体量 | `mota50-data.js` 46,771 B | `mota-data.js` **90,725 B**（近两倍） |
| 地形图例 | 12 条 | **231 条** |
| 对白覆盖 | `wiserWord`/`traderWord` 51 槽位但只写到 48 层 | `oldmanHints` **23** 条 + `traders` **9** 条 + `cutscenes` **13** 条 |
| 事件完整度 | 上游 README 自述「**只写完了前 10 层的事件部分**」 | `floors[].talk/step/auto/first` 覆盖 **24 层**，事件操作 25 种 |
| 地图形态 | 11×11，假墙静态烘入 | 13×13，暗墙运行时 `closeWall` 生成 |
| 本项目取它什么 | 道具语义、图例编号、怪物数值 | **对白文本** + 事件设计参照 |

## 6. 本项目从本目录**采用 / 未采用**的清单

采用（见 `data/npcs.json` 的 `$comment` 与 `tools/import-deluxe-dialogue.mjs`）：

| 来源表 | 落到本项目 | 结果 |
|---|---|---|
| `oldmanHints[].text\|oldman` | `npcs.sage.talkByFloor` | **3 → 23 层**（新增 20 / 替换 2） |
| `oldmanHints[].trader` + `traders[].text` | `npcs.merchant.talkByFloor` | **1 → 10 层**（新增 9） |
| `step[].acts` 里 `小偷` 的 `text` | `npcs.thief.talkByFloor["2"]` | 3 句自撰 → **原版** |
| `step[].acts` 里 `洋娃娃` 的 `text` | `npcs.princess.talkByFloor["26"]` | 新增 1 句 |

**有意不采用**：

- **作者（`author`）的台词**：1 层那句说的是「欢迎来到《魔塔50层》**原版复刻**」——那是
  **deluxe 这个复刻项目自己的标语**（`img=king`，作者口吻），属它的元信息而非原版游戏内容。
  本项目同样是复刻，引用它 = 让自己也说「原版复刻」，语义错位。
  （而且本项目 1 层 `(6,9)` 站的是 `sage`，本来就没有 `author` 实体 —— 落表会变成「写了没人读」，
  校验器的 `neverPlaced` 会报出来。相关代码：`ALLOW_FLAGGED` 白名单附近的注释。）
- **含条件（`flag`/`if`）的台词**：默认不收，只有白名单 `ALLOW_FLAGGED = { thief: [2], princess: [26] }`
  例外（那两处的台词就是这个 NPC 说的原话，且本项目**已用自撰台词实现了同一段剧情**）。
  ⚠️ **不要改成「凡是有台词的都收」** —— 那会把「营救公主后才生效」的条件台词变成随口就说的。
- **4 条无处落地的台词**（sage 23 层无载体 / thief 15、35 层无实体 / thief 29 层属剧情分支）
  —— 无 NPC 实体承接，落表即死数据，**丢弃并记录在案**。
